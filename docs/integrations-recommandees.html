Météo

  • Met.noNatif HA
    Service météo norvégien utilisé par défaut par Home Assistant, bonnes prévisions pour l'Europe dont la Suisse.
    Documentation
  • OpenWeatherMapNatif HA
    Intégration météo alternative avec API gratuite, prévisions horaires/quotidiennes et alertes.
    Documentation
  • AccuWeatherNatif HA
    Source météo tierce très précise, alternative à Met.no pour comparer les prévisions locales.
    Documentation
  • Pirate WeatherHACS
    Remplaçant de l'ancienne intégration Dark Sky, prévisions granulaires (minute-by-minute) appréciées de la communauté.
    Dépôt GitHub

Chauffage / climat (KNX et pilotage par zones)

  • KNXNatif HA
    Intégration officielle du bus KNX, expose thermostats/vannes KNX comme entités climate natives.
    Documentation
  • Versatile ThermostatHACS
    Thermostat évolué se posant au-dessus des entités climate KNX : presets, détection fenêtre ouverte, présence, surpuissance par zone.
    Dépôt GitHub
  • Generic ThermostatNatif HA (helper)
    Permet de créer des thermostats logiciels par pièce à partir d'un capteur de température et d'un actionneur KNX.
    Documentation
  • Scheduler ComponentHACS
    Planification avancée (horaires par zone/pièce) pilotable via une carte dédiée, idéal pour un chauffage multi-zones.
    Dépôt GitHub
  • Climate Group HelperHACS
    Regroupe plusieurs entités climate KNX en une seule zone logique pilotable d'un coup.
    Documentation

Éclairage

  • KNXNatif HA
    Pilotage natif des sorties lumière/dimmer du bus KNX (on/off, variation, couleur DALI le cas échéant).
    Documentation
  • Adaptive LightingHACS
    Ajuste automatiquement luminosité et température de couleur selon l'heure du jour et le lever/coucher du soleil — l'intégration HACS la plus installée pour l'éclairage.
    Dépôt GitHub
  • Philips HueNatif HA
    Utile si des lampes d'appoint/décoratives Hue viennent compléter l'éclairage filaire KNX.
    Documentation

Volets roulants / stores

  • KNXNatif HA
    Pilotage natif des actionneurs de volets KNX (montée/descente, position, lamelles).
    Documentation
  • Adaptive CoverHACS
    Calcule automatiquement la position idéale des stores selon la position du soleil, pour l'ombrage passif et les économies de chauffage/clim.
    Dépôt GitHub
  • Cover Time BasedHACS
    Reconstitue une position précise (%) pour des volets pilotés en tout-ou-rien, utile si certains actionneurs KNX ne remontent pas de position absolue.
    Dépôt GitHub

Sécurité / alarme

  • AlarmoHACS
    Système d'alarme complet (armé/désarmé, zones, codes, notifications) directement dans HA — référence pour remplacer une centrale d'alarme propriétaire.
    Dépôt GitHub

    Panneau d'alarme basique intégré au cœur de HA, base sur laquelle Alarmo s'appuie, ou alternative légère.
    Documentation
  • KNX (binary_sensor)Natif HA
    Remonte les contacts de porte/fenêtre et détecteurs câblés sur le bus KNX comme capteurs binaires utilisables par Alarmo.
    Documentation

  • FrigateHACS + conteneur Docker
    NVR local avec détection d'objets par IA (personne, véhicule, animal) sur GPU/Coral — la référence pour la vidéosurveillance self-hosted intégrée à HA.
    Documentation
  • ReolinkNatif HA
    Intégration officielle pour caméras Reolink (marque répandue en auto-hébergement, compatible ONVIF/RTSP).

  • Generic Camera (RTSP/ONVIF)Natif HA
    Permet de connecter n'importe quelle caméra IP standard via flux RTSP/MJPEG, sans dépendre d'une marque.
    Documentation

Énergie / solaire

    Documentation
  • Forecast.SolarNatif HA

    Documentation
  • Solcast PV ForecastHACS
    Prévisions solaires plus précises basées sur des données satellite — référence communautaire pour affiner la prévision de production PV.

  • Power Flow Card PlusHACS

  • TeslaMateDocker auto-hébergé (gratuit) + MQTT

HACS (Home Assistant Community Store)

Gestionnaire de paquets communautaire qui ajoute un onglet dans Home Assistant pour installer, mettre à jour et gérer intégrations, cartes Lovelace, thèmes et add-ons développés par la communauté, absents du cœur officiel. C'est un prérequis avant d'installer la quasi-totalité des modules « HACS » listés ci-dessus (Frigate, Mushroom, Bubble Card, Alarmo, etc.) — sans lui, ces dépôts GitHub doivent être copiés manuellement dans custom_components/www et mis à jour à la main. Installation résumée pour une instance Docker : exécuter le script d'installation officiel dans le conteneur (ou copier manuellement le dossier hacs dans config/custom_components), redémarrer Home Assistant, ajouter l'intégration HACS depuis Paramètres → Appareils et services, puis s'authentifier via GitHub. Documentation d'installation

Home Assistant MCP Server (Model Context Protocol)

  • Model Context Protocol ServerNatif HA
    Expose les entités, services et automatisations de Home Assistant à un client MCP externe (comme Claude), permettant à un assistant IA de lire l'état de la maison et de déclencher des actions directement.
    Documentation
  • hass-mcpProjet communautaire (voska)
    Serveur MCP alternatif orienté configuration/développement : permet à Claude de contrôler et interroger une instance HA en Docker pour écrire de la config YAML, diagnostiquer des entités KNX/Tesla, ou générer des automatisations directement depuis la conversation.
    Dépôt GitHub

Dans le contexte du projet (HA en Docker, bus KNX, Tesla à venir), ces deux briques permettent à Claude d'agir comme un « copilote de configuration » : lire les entités KNX existantes, proposer des automatisations de chauffage par zone, ou déboguer l'intégration Tesla/solaire sans copier-coller manuel de configuration.
